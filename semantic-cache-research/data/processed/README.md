# processed/

The generated and verified corpus, ready for experiments: paraphrase
group, hard-negative group, and unrelated group, each with engineered
ground-truth labels.

Files here are produced by src/dataset_generation/ scripts. This
folder should be treated as regenerable in principle, but in practice
the manual-verification step (see verification_report.md) is expensive
to redo, so back this up once verification is complete.
